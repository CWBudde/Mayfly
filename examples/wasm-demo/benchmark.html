Seven variants, one honest table

"DESMA beat standard MA" is not a result until you say how many runs, at what seeds, and whether the gap survives a significance test. The library ships a comparison framework that answers all three; this page is that framework, running in your browser.

Every run at index k uses the same seed for every variant, so the samples are genuinely paired — which is the only thing that makes the signed-rank test below legitimate.

Significance

Pairwise Wilcoxon signed-rank tests over the paired runs, plus the Friedman test across all variants. A cell shows the winner only when p < 0.05; everything else is a tie you should not read into.

Run a sweep to see the tests.

Reading the numbers

Timings are not native Go. Under js/wasm everything runs on one thread with no SIMD, and the library's parallel evaluation is switched off because a goroutine pool buys nothing here. Treat the millisecond column as a relative cost between variants, never as a benchmark of the library.

Small sweeps prove little. The quick preset runs 5 trials; the library defaults to 30 for a reason. A Wilcoxon result over 5 paired samples can only detect an enormous effect, so an absence of significance here is an absence of evidence, not evidence of absence.

Bounds are per function, taken from each benchmark's usual domain rather than one shared range, which is why costs are not comparable across columns of the chart.
